# 天才ラッシュ∞ (GENIUS RUSH INFINITY)

誰でも解ける二択を即答するだけで、IQが 万 → 億 → 兆 → … → 無量大数 とインフレしていく、スマホ片手用のゲーム。

https://tomosud.github.io/web_simple_apps/genius_rush/

## 遊び方

- 画面下の2枚のパネルのうち、正しい方をタップするだけ（PCは ← / → キー）
- 速く答えるほど獲得IQが増え、連続正解（COMBO）で倍率が上がる
- BONUSゲージが貯まるとボーナス発生
  - **神託スロット**: タップで3つのリールを止める。揃うとIQが ×10 〜 ×1京。`７７７` と `神神神` は **覚醒FEVER**（獲得IQ ×1000・無敵）に突入
  - **天啓の三択**: 3枚から1枚選ぶ
- 間違い・時間切れでライフ（◆）が1つ減る。0になると一度だけ **LAST CHANCE**（復活 or 終了）
- 進むほど制限時間が短くなる。最終IQと称号が記録される（自己ベストは端末に保存）

## 演出について

- スロットの結果は回す前に決まっており、止めるタイミングは結果に影響しない（リーチ・あと1コマ・復活はすべて演出）
- 三択カードは、選んだ1枚が必ず最高の当たりになる
- 表示されるIQはフィクション。課金・賭けの要素はない
- タイトル画面の「演出ひかえめ」で、画面フラッシュ・画面揺れ・振動を止められる

## 構成

ビルド不要の静的ファイルのみ。GitHub Pages にそのまま置ける。

```
genius_rush/
├── index.html       # 画面の骨組み
├── style.css        # 見た目・アニメーション
├── js/
│   ├── num.js       # 巨大数（log10で保持、万〜無量大数の表記）
│   ├── audio.js     # WebAudioで合成する効果音とBGM（音声ファイルなし）
│   ├── fx.js        # 背景ワープとパーティクル（Canvas）
│   ├── questions.js # 問題ジェネレータ
│   └── game.js      # ゲーム進行・スロット・FEVER・リザルト
└── run.bat          # ローカル確認用（python -m http.server 8131）
```

- 外部依存は Google Fonts（Dela Gothic One / Orbitron）のみ。読めなくても標準フォントで動く
- URLに `?debug` を付けると時間切れが無くなり、`GR.debug` から各ボーナスを直接呼べる
