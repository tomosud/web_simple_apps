# 16茶 — 十六夜の茶会

「隠された量を見抜く」と「注ぐ順番を組み立てる」を楽しむ、全8席の推理パズルです。
`tea_game.html` をブラウザで開くと遊べます。同じフォルダの `tea.css`、`game-core.js`、`game.js` も必要です。ビルド・外部ライブラリ・通信は不要です。

## 基礎ルール

- 4色の元の量は **1・2・3・4がひとつずつ**。各席の手がかりはすべて本当です。
- 合計・大小の手がかりから量を推理し、色のボタンを押して注ぎます。
- **16ぴったりで完成。16を超えた瞬間に、その一杯は失敗**。超過後に取り消したり、飲んで戻したりはできません。
- 注ぐと1手を使います。「量を調べる」→色の選択で、注がずに1手で量を確認できます（1席1回）。
- 候補表示は、観測済みの量の消去だけを補助します。関係の手がかりの答えまで自動では表示しません。
- 基本は各色2回まで。在庫・次の倍率・必須の注文は画面に表示されます。
- 時間制限はありません。失敗してもその席から再挑戦でき、解き方は自分で開いた時だけ見られます。

## なぜ8席にしたか

従来は、一度量がわかると最大の茶を繰り返して足すだけになりがちでした。今回は、推理が終わった後にも判断が残るようにしました。

| 席 | 発展 | 考えること |
| --- | --- | --- |
| 1 消えたラベル | 2色だけ不明、大小の手がかり | 残る2と3を見分け、ひと注ぎで成功する |
| 2 ふたりの証言 | 合計＋大小、任意の注文 | 普通の完成と、3色使う完成の違い |
| 3 最後の茶葉 | 各色1回きり | 繰り返せない茶葉をどう選ぶか |
| 4 こだまの茶器 | 2回目の注ぎだけ×2 | 同じ量でも順番で合計が変わる |
| 5 目覚める茶葉 | 同じ色の2回目は＋1 | 元の量と、実際に注ぐ量を分けて考える |
| 6 ふた色の約束 | 指定の2色が必須 | 単に16にするだけでは注文を満たせない |
| 7 月下の一煎 | 在庫1回＋2回目×2 | 覚えた仕組みを組み合わせる |
| 8 十六夜の招待状 | 在庫1回＋3回目×2＋指定色 | 3色で完成する道と、4色を使う別解を探す |

新ルールは登場する直前に説明します。初回に全部は説明しません。配合は手がかりから一意に決まり、運任せでしか進めない問題にはしていません。

## 道具と追加の注文

3席目の後に旅の相棒を選べます。地図から変更でき、変更は次に始める席から適用されます。

- **透かし眼鏡**：量の調査が手数0になる。各席1回。
- **月の茶匙**：手数0で合計を1減らせる。各席1回。超過後は使用不可。

各席の星は3種類です。

1. 16で完成する。
2. 調査・道具・考え方のヒントを使わずに完成する。
3. 「3色使う」「特定の色で締める」などの任意の注文を満たす。

任意の注文に失敗しても次へ進めます。必須の注文は第6席・第8席だけで、画面に別表示します。再挑戦でも星3つを狙えます。

八席踏破で結末が開きます。未達の注文に挑戦したり、色ラベルを入れ替えた茶会を遊んだりできます。ラベル変更は同じパズル構造の再配置です。

## 保存と操作

- 解放済みの席、各席の最高評価、道具、途中の一杯を `localStorage` の `tea16_moon_v1` に保存します。旧版の記録キーは変更しません。
- 保存データは操作履歴から再計算して検証し、不整合があれば再開しません。
- ストレージが利用できなくてもプレイできます。
- 320×568からの縦画面に対応。高さが足りない横向き・拡大時は縦スクロールできます。
- タップのみで操作可能。色名・記号・数字を併用し、キーボード、ダイアログ内フォーカス、動きを減らす設定、セーフエリアに対応します。

## ファイルと検証

- `tea_game.html`：画面の構造
- `tea.css`：スマホ向け表示と演出
- `game-core.js`：8席のデータ、純粋な状態遷移、解探索
- `game.js`：導入、画面更新、進行、道具、保存
- `verify.cjs`：依存ライブラリなしのルール検証（`node 16tea/verify.cjs`）
- `output/playwright/verify.js`：実際のボタン操作で八席すべてを星3つでクリア
- `output/playwright/verify-mobile.js`：全席の開始時・プレイ途中の画面サイズ検証
- `output/playwright/verify-flows.js`：失敗、再挑戦、途中再開、道具変更、タッチ調査、保存禁止、フォーカスの検証

ブラウザ用の検証ファイルは Playwright CLI の `run-code` に渡す関数です。専用のローカルテストページで実行してください。テスト用のゲーム状態と保存データを操作します。

検証内容：320配合の推理の一意性、640通りの通常・任意注文の解、超過・手数切れ・在庫・倍率・濃さ・必須注文・道具の状態遷移。ブラウザでは8席の通しプレイ、320×568 / 375×667 / 390×844 / 768×1024 / 1280×800、タッチ操作と保存禁止環境を確認しています。実機のiOS Safariなどでは未検証です。
