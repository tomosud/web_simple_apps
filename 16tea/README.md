# 16茶 — ぴったり、ひといき。

4色のお茶の隠れた量を探し、限られた手数で合計16を作るパズルです。
`tea_game.html` をブラウザで開くだけで遊べます。外部ライブラリ・通信・ビルドは不要です。

## 遊び方

- 初回は緑茶を2回押す練習から始められます。説明は右上の「?」からいつでも確認できます。
- 各色の量は +1 / +2 / +3 / +4 が1つずつ。注ぐと量が判明し、未確認の色には残りの候補を表示します。
- 合計16で完成。16を超えるか、16になる前に手数がなくなると失敗です。
- 注ぐ・ひとくち飲む（−1）はそれぞれ1手。飲んでから注ぐ調整もできます。
- 「量を見る」は手数を使わず1色確認できます（1杯1回）。
- 「1手戻す」は直前の量と手数を復元します（1杯1回）。見つけた量は保持し、失敗直後にも使えます。
- 結果は自動で消えません。失敗時は正解例を確認し、同じ問題に再挑戦できます。

## 遊び続ける仕組み

- 1〜3杯目は6手、4〜8杯目は5手、9杯目以降は4手。最初の量は4〜7で、最初から役立つ1色が見えています（1杯目のみ2色）。
- 各問題は必ず手数内に解答があります。次の杯では配合が変わります。
- 星1つ：完成。星2つ：サポートなし。星3つ：さらに2手以上残して完成。
- 量の確認・手戻し・再挑戦はサポートとして星1つになります。
- 得点は星×100＋残り手数×20＋連続完成ボーナス。5杯ごとに次の章へ進み、5・10・20杯で称号が上がります。
- 最高完成杯数と最高得点を `localStorage` の `tea16_v2` に保存します。保存が使えなくてもプレイできます。旧記録 `tea16_hs` はそのまま残します。
- 途中の盤面は保存しません。再読み込みや入口からの開始は1杯目からです。

## スマホ・アクセシビリティ

- 縦画面320×568以上で主要操作が1画面に収まるよう調整しています。
- 素材ボタンは高さ64px以上、補助ボタンは46px。スワイプ・ドラッグ不要です。
- 横向きなど高さが足りない画面は縦スクロールできます。
- 拡大操作、セーフエリア、キーボード操作、ダイアログ内フォーカス、動きを減らす設定に対応。
- 色に加えて名前・記号・数値で区別します。

## 検証

`output/playwright/verify.js` は Playwright CLI の `run-code` に渡すブラウザ検証です。専用のテストページで実行してください（ゲーム状態とテスト用の記録を操作します）。

- 7段階×200問＝1400問の数値の重複なし・解答可能性
- 練習、超過、手数切れ、最終手での完成、手戻し、飲む、再挑戦、量の確認、得点、操作ガード
- 320×568 / 375×667 / 390×844 / 768×1024 / 1280×800 の画面内表示
- 667×375の横向きで横スクロールが発生しないこと

`output/playwright/mobile.png` は375×667の画面です。実機スマホの検証ではなく、Chromiumでの画面サイズ検証です。
